# Metodologia de Trabalho
<div class="hr-gold"></div>

1. **Levantamento e diagnóstico**
   - Reunião inicial, recolha de informação e documentação
   - Mapeamento de processos e necessidades

2. **Planeamento**
   - Definição de escopo, cronograma e entregáveis
   - Definição de responsabilidades e forma de acompanhamento

3. **Execução**
   - Implementação técnica por área (gestão, finanças, TI, jurídico, arquitetura)
   - Validações por marcos

4. **Acompanhamento**
   - Relatórios periódicos
   - Indicadores e ajustes necessários

5. **Encerramento e transferência**
   - Documentação final
   - Treinamento/capacitação quando aplicável
